# Technology Decision Log

## Next.js
Chosen for a unified production web application with routing, server-side capabilities and deployment compatibility.

## TypeScript
Chosen to reduce runtime errors and improve maintainability for a multi-module application.

## PostgreSQL
Chosen for relational integrity and structured regulatory/test data.

## Supabase
Chosen to accelerate authentication, PostgreSQL access and protected file storage.

## Tailwind CSS
Chosen for rapid construction of a consistent responsive design system.

## Vercel
Chosen for straightforward deployment and CI/CD integration with GitHub.

## Architecture Principle
Prefer simple, modular and auditable technology over unnecessary complexity.
