# Technology Stack

| Layer | Technology | Purpose |
|---|---|---|
| Frontend | Next.js | Production web application |
| Language | TypeScript | Type-safe application development |
| Styling | Tailwind CSS | Responsive UI |
| Components | shadcn/ui | Consistent professional interface |
| Backend | Next.js API / Server Actions | Application logic |
| Database | PostgreSQL | Structured project/test data |
| Auth | Supabase Auth | Login and role management |
| Storage | Supabase Storage | Reports, certificates, evidence |
| Validation | Zod | Request/form validation |
| Charts | Recharts | Test and compliance visualizations |
| Hosting | Vercel | Web deployment |
| Repository | GitHub | Source control and collaboration |

## Design Principles
1. Modular architecture
2. Secure-by-default access control
3. Traceable test records
4. Responsive desktop/tablet interface
5. Accessible UI
6. Clear separation of UI, business logic and data
7. Auditability of important actions
