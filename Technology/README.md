# MetroLab — Technology Folder

This folder documents the technical foundation of the MetroLab NAWI (Non-Automatic Weighing Instruments) digital verification and compliance platform.

## Purpose
MetroLab is designed as a modern web platform for:
- NAWI model/test workflow management
- OIML R76-aligned test execution support
- Digital test records and evidence
- Instrument/model information
- Compliance calculations and results
- Role-based access
- Reports and audit trails

## Suggested Stack
- Frontend: Next.js + TypeScript
- UI: Tailwind CSS + shadcn/ui
- Backend/API: Next.js API routes / server actions
- Database: PostgreSQL
- Authentication: Supabase Auth
- Storage: Supabase Storage
- Validation: Zod
- Charts: Recharts
- Deployment: Vercel
- Version Control: Git + GitHub

> Technology choices can be changed during implementation without changing the product concept.
