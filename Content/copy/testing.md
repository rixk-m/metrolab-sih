# Testing

## Typical test workflow
1. Register the instrument
2. Record identification and technical parameters
3. Select the applicable test procedure
4. Perform measurements
5. Record observations and environmental conditions
6. Evaluate errors against applicable criteria
7. Review the test record
8. Generate the final report

## Example test categories
- Zero-setting / zero indication
- Repeatability
- Eccentric loading
- Weighing performance
- Tare-related tests
- Indication and display checks
- Environmental or influence-factor tests where applicable
