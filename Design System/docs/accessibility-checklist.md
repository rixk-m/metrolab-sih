# MetroLab Accessibility Checklist

- [ ] All interactive controls have visible keyboard focus.
- [ ] Text and UI controls maintain adequate contrast in both themes.
- [ ] Status is not communicated by color alone.
- [ ] Tables have meaningful headers and scope.
- [ ] Form fields have persistent labels.
- [ ] Errors are associated with the relevant field and explained.
- [ ] Dialogs trap focus and have accessible names.
- [ ] Charts have textual summaries or data alternatives for critical information.
- [ ] Touch targets are approximately 44px or larger on mobile where practical.
- [ ] Motion respects reduced-motion preferences.
