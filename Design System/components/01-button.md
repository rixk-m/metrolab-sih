# Button
Primary actions use the MetroLab brand color. Secondary actions are outlined or neutral. Destructive actions use danger only for irreversible operations.

Variants: primary, secondary, ghost, danger, icon.
Sizes: sm (32px), md (40px), lg (48px).
States: default, hover, focus-visible, pressed, disabled, loading.
Rule: one primary button per visually dominant card/section where possible.
