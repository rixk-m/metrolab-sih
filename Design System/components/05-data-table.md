# Data Table
Use for instrument records, test results, verification logs and audit history.

Header: semibold, muted surface.
Rows: 48–56px depending on density.
Numeric measurement columns are right-aligned and use tabular numerals.
Recommended columns: ID, Instrument/Model, Parameter, Result, Status, Date, Action.
Keep row actions to 1–2 primary options; additional actions go in a menu.
