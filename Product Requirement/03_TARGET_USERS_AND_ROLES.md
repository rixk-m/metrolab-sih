# Target Users & Roles

## Administrator
Manage users, roles, configuration, authorized ruleset versions and system activity.

## Evaluator
Create evaluations, enter observations, review calculations, attach evidence and submit for review.

## Reviewer
Inspect observations/calculations/compliance, add remarks, request changes and approve.

## Approving Officer
Perform final approval and digital signature where enabled.

## Viewer
Read-only access to authorized instruments, evaluations, reports and history.

Authorization must be enforced server-side; hiding UI controls is not sufficient security.
