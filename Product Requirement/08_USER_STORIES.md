# User Stories

## Evaluator
- Create evaluations from registered instruments.
- Enter structured observations.
- Reduce repetitive calculations.
- Understand how results were calculated.
- Recover work through autosave.
- Attach evidence.
- Submit for review.

## Reviewer
- Review all observations/calculations in one place.
- Identify failures/warnings.
- Request changes with remarks.
- Inspect audit history.

## Approving Officer
- Perform final review.
- Finalize/sign controlled reports.

## Administrator
- Manage users and roles.
- Control ruleset versions.
- Inspect audit activity.

## Viewer
- Search and view authorized reports/history without editing.
