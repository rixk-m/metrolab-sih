# Problem Statement

NAWIs such as electronic scales, platform scales and weighbridges require accurate technical and metrological evaluation where applicable. Type evaluation involves recording observations, performing calculations, determining compliance and producing detailed reports.

Manual spreadsheet/document workflows can create repetitive work, calculation errors, inconsistent reports, weak traceability and difficult historical retrieval.

METROLAB digitizes the workflow:

Instrument → Evaluation → Conditions → Tests → Observations → Calculations → Compliance → Review → Approval → Report → Repository/History.

METROLAB is software supporting the evaluation workflow; it does not replace the authority or laboratory decision-making process.
