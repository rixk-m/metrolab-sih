# METROLAB — Product Requirements

This folder defines WHAT the METROLAB product must do.

METROLAB is a digital platform for NAWI type evaluation, supporting instrument registration, evaluation setup, structured OIML R76 test workflows, calculations, compliance evaluation, review, standardized reporting, repository/history, analytics, RBAC and auditability.

Important: regulatory calculations and compliance rules must use a verified, versioned source/ruleset. Never invent regulatory requirements.
