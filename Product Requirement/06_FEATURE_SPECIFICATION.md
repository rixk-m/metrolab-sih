# Feature Specification

## Public Website
- typography-led welcome
- immersive 3D laboratory
- scroll-driven camera/object animation
- interactive weighing instrument
- problem/solution storytelling
- OIML R76 explanation
- workflow visualization
- report visualization
- dark/light mode
- transition into application

## Application
### Dashboard
KPIs, recent evaluations, pending work and analytics.

### Instruments
List, search, filters, profile and history.

### New Evaluation
Wizard, validation, autosave and review.

### Test Workspace
Test navigation, observations, live calculations, compliance, attachments and optional 3D test visualizer.

### Review
Summary, failed/warning items, remarks, changes and approval.

### Reports
Generate, preview, export, version and history.

### Repository
Search, filters and report/history access.

### Administration
Users, roles, rulesets, configuration and audit.
