# Non-Functional Requirements

## Accuracy
Calculations must be deterministic and tested.

## Traceability
Results must be traceable to observations, calculation logic, ruleset version, user and timestamp.

## Security
Authentication, server-side authorization, RLS where applicable, secure storage, input validation and secret protection.

## Performance
Responsive forms, search, dashboards and report generation.

## 3D Performance
Optimized models, lazy loading, dynamic imports, adaptive rendering, mobile simplification and reduced-motion mode.

## Accessibility
Keyboard navigation, visible focus, adequate contrast, semantic labels and reduced-motion support.

## Responsiveness
Desktop, tablet and mobile.

## Maintainability
Business logic must remain separate from UI.

## Extensibility
Support future tests, instrument types, rulesets, report templates, roles and integrations.

## Reliability
Autosave, recovery, backups and controlled migrations.

## Auditability
Important business actions must be recorded.

## Usability
Users must understand required fields, validation errors, calculation reasoning and next actions.
